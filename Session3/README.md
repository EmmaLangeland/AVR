# Task 2: ADC-OLED
Open project ADC-OLED.X

This task has two parts.

In the first part you will write a word to the OLED screen.

In the second part you will continuously update the screen to show the ADC output from a potentiometer. 
You should also be able to pause the screen updates to show the Omega Verksted logo.
